Circle's **Cross-Chain Transfer Protocol (CCTP)** supports native USDC transfers between Stellar and other CCTP-enabled chains — no wrapped assets, no third-party bridges.

<Info>

**Full documentation**

CCTP on Stellar is documented and maintained by Circle. For contract addresses, supported chains, SDKs, code samples, and the attestation API:

[CCTP on Stellar — Circle developer docs](https://developers.circle.com/cctp/references/stellar)

</Info>

This page covers the Stellar-specific parts of a transfer that starts on Stellar: the allowance the burn needs, how to get the destination mint done, and a worked example. For transfers into Stellar, follow Circle's [`CctpForwarder` guide](https://developers.circle.com/cctp/references/stellar#use-cctpforwarder-for-stellar-recipients).

## Transfer flow from Stellar

A transfer from Stellar to another chain has three steps:

1. **Burn.** Call `deposit_for_burn` or `deposit_for_burn_with_hook` on the `TokenMessengerMinter` contract. The contract burns your USDC and emits a CCTP message.
2. **Attest.** Circle's attestation service signs the message. Fetch the message and attestation with `GET /v2/messages/27?transactionHash=<hash>`. Stellar's CCTP domain is `27`. Use the Stellar transaction hash as it is, with no `0x` prefix.
3. **Mint.** Someone calls `receiveMessage` on the destination chain's `MessageTransmitterV2` contract with the message and attestation. That can be you or a relayer. See [relayer options](#relayer-options).

Circle lists Fast Transfer as not applicable for Stellar, because a standard attestation is already fast. A burn from Stellar attests at the finalized threshold (`2000`), even when you request `1000`.

### Burn arguments

`deposit_for_burn` takes these arguments. `deposit_for_burn_with_hook` takes the same arguments plus `hook_data`.

| Argument | Type | Value |
| --- | --- | --- |
| `caller` | `Address` | The address that holds the USDC. It must authorize the call. |
| `amount` | `i128` | The amount to burn, in Stellar's 7-decimal USDC units. |
| `destination_domain` | `u32` | The [CCTP domain](https://developers.circle.com/cctp/concepts/supported-chains-and-domains#domain-identifiers) of the destination chain, for example `6` for Base. |
| `mint_recipient` | `BytesN<32>` | The recipient on the destination chain, as 32 bytes. Left-pad a 20-byte EVM address with zeros. For Solana, use the recipient's USDC token account. |
| `burn_token` | `Address` | The USDC Stellar Asset Contract (SAC). |
| `destination_caller` | `BytesN<32>` | The only address allowed to call `receiveMessage`. 32 zero bytes allow anyone. |
| `max_fee` | `i128` | The highest fee you accept, in 7-decimal USDC units. |
| `min_finality_threshold` | `u32` | `2000` for a standard transfer. |
| `hook_data` | `Bytes` | `deposit_for_burn_with_hook` only. Data for the destination, such as the Forwarding Service hook. |

Stellar USDC has 7 decimals, while CCTP messages use 6. The burn takes only the first 6 decimals of `amount`, and the 7th decimal stays in your account. See [USDC precision](https://developers.circle.com/cctp/references/stellar#usdc-precision-for-cctp-and-stellar) in Circle's docs.

The contract addresses are in Circle's [Stellar contracts list](https://developers.circle.com/cctp/references/stellar-contracts). The USDC SAC addresses are:

| Network | USDC SAC                                                   |
| ------- | ---------------------------------------------------------- |
| Mainnet | `CCW67TSZV3SSS2HXMBQ5JFGCKJNXKZM7UQUWUZPUTHXSTZLEO7SJMI75` |
| Testnet | `CBIELTK6YBZJU5UP2WWQEUCYKLPU6AUNZ2BQ4WWFEIE3USCIHMXQDAMA` |

## The allowance requirement

`TokenMessengerMinter` does not take USDC with a `transfer` that you authorize. It pulls USDC from `caller` with `transfer_from` on the USDC SAC. So before the burn, `caller` must `approve` the `TokenMessengerMinter` contract as a spender for at least `amount`. See the [token interface](/docs/tokens/token-interface) for `approve` and `transfer_from`.

A transaction can hold only one `InvokeHostFunctionOp` (see [Stellar transactions](/docs/learn/fundamentals/contract-development/contract-interactions/stellar-transaction)). So by default, a transfer from Stellar takes two transactions and two signatures: `approve`, then `deposit_for_burn`. To get to one signature, use one of these options.

### Option 1: a wrapper contract

Deploy a contract that calls `approve` and then `deposit_for_burn` in one invocation. One user signature covers the wrapper call and every authorization that the inner `approve` and `deposit_for_burn` calls need. The [stellar-cctp-demo](https://github.com/ElliotFriend/stellar-cctp-demo) repository has an example wrapper in `contracts/stellar/cctp-wrapper`:

```rust
pub fn approve_and_deposit(
    env: Env,
    tmm: Address,
    caller: Address,
    amount: i128,
    destination_domain: u32,
    mint_recipient: BytesN<32>,
    burn_token: Address,
    destination_caller: BytesN<32>,
    max_fee: i128,
    min_finality_threshold: u32,
) {
    caller.require_auth();

    // approve an allowance so the TokenMessengerMinter contract can `transfer_from` our caller address
    let live_until_ledger = (env.ledger().sequence() + 50).next_multiple_of(50);
    token::Client::new(&env, &burn_token).approve(&caller, &tmm, &amount, &live_until_ledger);

    let tmm_client = TmmClient::new(&env, &tmm);
    tmm_client.deposit_for_burn(
        &caller,
        &amount,
        &destination_domain,
        &mint_recipient,
        &burn_token,
        &destination_caller,
        &max_fee,
        &min_finality_threshold,
    );
}
```

The same contract has `approve_and_deposit_with_hook`, which passes `hook_data` on to `deposit_for_burn_with_hook`.

<Warning>

The demo wrapper is example code, and it is deployed on testnet only. Review and audit any wrapper contract before you use it on mainnet.

</Warning>

### Option 2: an existing allowance

Approve the `TokenMessengerMinter` once, for a larger amount and a later expiration ledger. Each later burn then needs only one signature, until the allowance is spent or expires.

Know the tradeoffs:

- The `TokenMessengerMinter` contract can pull USDC up to the allowance until it expires.
- An allowance is temporary storage with an expiration ledger. When it expires, the user must approve again.
- A burn fails when the remaining allowance is less than `amount`.

## Relayer options

After the burn and the attestation, a transaction on the destination chain must call `receiveMessage`. You have these options:

| Option | How it works | Tradeoffs |
| --- | --- | --- |
| Mint it yourself | Your app or backend calls `receiveMessage` on the destination chain. | You need a funded wallet on the destination chain, and the user may sign a second time there. There is no extra fee. You control timing and retries. |
| Circle Forwarding Service | Put the `cctp-forward` hook in `hook_data` and leave `destination_caller` as 32 zero bytes. Circle submits the mint and takes its fee from the minted USDC. | Nobody needs gas on the destination chain. With a wrapper contract, the whole transfer takes one user signature. The route must be one that Circle supports, and the fee comes out of the transfer. |
| Third-party relayer | Another service watches for the burn and calls `receiveMessage`. | Check the service's fees, supported routes, and what happens when a mint fails. |

To restrict the mint to one relayer, set `destination_caller` to that relayer's address. The Forwarding Service does not work when `destination_caller` is set.

### Use the Circle Forwarding Service

1. Check that Circle's [supported blockchains table](https://developers.circle.com/cctp/concepts/supported-chains-and-domains#supported-blockchains) lists the destination chain under "Forwarding Service".
2. Set `hook_data` to the 32-byte version 0 forwarding hook: `0x636374702d666f72776172640000000000000000000000000000000000000000`. This is `cctp-forward` followed by zero bytes. See Circle's [hook format](https://developers.circle.com/cctp/concepts/forwarding-service#hook-format).
3. Quote the fee with `GET /v2/burn/USDC/fees/27/<destination domain>?forward=true`. Use the entry with `finalityThreshold` `2000`. `minimumFee` is the protocol fee in basis points, and `forwardFee` is in 6-decimal USDC units.
4. Set `max_fee` to cover the protocol fee plus the forwarding fee, in Stellar's 7-decimal units. Multiply `forwardFee` by 10 to convert it.

Circle does not support upfront fees for transfers from Stellar, so the fee comes out of the minted amount. Circle does not refund a `max_fee` that is higher than the gas used, so do not add a large buffer. When the forward is done, the attestation response shows `forwardState` and `forwardTxHash`.

## Worked example

This example sends USDC from Stellar testnet to Base Sepolia with the Circle Forwarding Service. It uses two transactions, `approve` and then `deposit_for_burn_with_hook`, signed by a secret key. The TypeScript example uses `@stellar/stellar-sdk` v16, the Python example uses `stellar-sdk` 17, and the Go example uses `go-stellar-sdk` v0.9.0.

<CodeGroup>

```ts TypeScript
import {
  Address,
  Contract,
  Keypair,
  Networks,
  TransactionBuilder,
  nativeToScVal,
  rpc,
  xdr,
} from "@stellar/stellar-sdk";

// Testnet values. For mainnet, use Circle's mainnet contract list,
// the mainnet USDC SAC, and https://iris-api.circle.com.
const RPC_URL = "https://soroban-testnet.stellar.org";
const IRIS_URL = "https://iris-api-sandbox.circle.com";
const TOKEN_MESSENGER_MINTER =
  "CDNG7HXAPBWICI2E3AUBP3YZWZELJLYSB6F5CC7WLDTLTHVM74SLRTHP";
const USDC_SAC = "CBIELTK6YBZJU5UP2WWQEUCYKLPU6AUNZ2BQ4WWFEIE3USCIHMXQDAMA";
const STELLAR_DOMAIN = 27;
const BASE_DOMAIN = 6;

// "cctp-forward", hook version 0, no extra data
const FORWARD_HOOK = Buffer.from(
  "636374702d666f72776172640000000000000000000000000000000000000000",
  "hex",
);

const server = new rpc.Server(RPC_URL);
const signer = Keypair.fromSecret(process.env.STELLAR_SECRET_KEY!);

function evmAddressToBytes32(address: string): Buffer {
  const hex = address.toLowerCase().replace(/^0x/, "");
  if (!/^[0-9a-f]{40}$/.test(hex)) {
    throw new Error(`Invalid EVM address: ${address}`);
  }
  return Buffer.from(hex.padStart(64, "0"), "hex");
}

async function invoke(contractId: string, method: string, args: xdr.ScVal[]) {
  const account = await server.getAccount(signer.publicKey());

  // Bid what recent transactions paid, capped at what you're willing to spend.
  // prepareTransaction adds the resource fee on top of this inclusion fee.
  // This Stellar network fee is paid in XLM, apart from Circle's max_fee.
  const { sorobanInclusionFee } = await server.getFeeStats();
  const MAX_INCLUSION_FEE = 100_000; // stroops (0.01 XLM): pick your own cap
  const fee = String(
    Math.min(Number(sorobanInclusionFee.p90), MAX_INCLUSION_FEE),
  );

  const tx = new TransactionBuilder(account, {
    fee,
    networkPassphrase: Networks.TESTNET,
  })
    .addOperation(new Contract(contractId).call(method, ...args))
    .setTimeout(60)
    .build();

  const prepared = await server.prepareTransaction(tx);
  prepared.sign(signer);
  const sent = await server.sendTransaction(prepared);
  if (sent.status !== "PENDING") {
    throw new Error(`Submit failed: ${sent.status}`);
  }
  const result = await server.pollTransaction(sent.hash);
  if (result.status !== rpc.Api.GetTransactionStatus.SUCCESS) {
    throw new Error(`Transaction failed: ${result.status}`);
  }
  return sent.hash;
}

async function quoteMaxFee(amount: bigint): Promise<bigint> {
  const res = await fetch(
    `${IRIS_URL}/v2/burn/USDC/fees/${STELLAR_DOMAIN}/${BASE_DOMAIN}?forward=true`,
  );
  const quotes = await res.json();
  const quote = quotes.find((q: any) => q.finalityThreshold === 2000);
  if (!quote) {
    throw new Error("No fee quote for finality threshold 2000");
  }
  // The live API returns forwardFee.med. Circle's spec names it medium.
  const forwardFee = quote.forwardFee.med ?? quote.forwardFee.medium;
  // minimumFee is in basis points. forwardFee uses 6 decimals, so
  // multiply by 10 for Stellar's 7-decimal units.
  const protocolFee =
    (amount * BigInt(Math.ceil(quote.minimumFee * 100))) / 1_000_000n;
  return protocolFee + BigInt(forwardFee) * 10n;
}

async function waitForAttestation(txHash: string) {
  while (true) {
    const res = await fetch(
      `${IRIS_URL}/v2/messages/${STELLAR_DOMAIN}?transactionHash=${txHash}`,
    );
    if (res.ok) {
      const { messages } = await res.json();
      if (messages?.[0]?.status === "complete") return messages[0];
    }
    await new Promise((resolve) => setTimeout(resolve, 5000));
  }
}

async function bridgeToBase(amount: bigint, evmRecipient: string) {
  const caller = signer.publicKey();
  const maxFee = await quoteMaxFee(amount);

  // Transaction 1: let the TokenMessengerMinter pull `amount` USDC.
  const { sequence } = await server.getLatestLedger();
  await invoke(USDC_SAC, "approve", [
    new Address(caller).toScVal(),
    new Address(TOKEN_MESSENGER_MINTER).toScVal(),
    nativeToScVal(amount, { type: "i128" }),
    nativeToScVal(sequence + 100, { type: "u32" }),
  ]);

  // Transaction 2: burn with the forwarding hook.
  const burnHash = await invoke(
    TOKEN_MESSENGER_MINTER,
    "deposit_for_burn_with_hook",
    [
      new Address(caller).toScVal(),
      nativeToScVal(amount, { type: "i128" }),
      nativeToScVal(BASE_DOMAIN, { type: "u32" }),
      nativeToScVal(evmAddressToBytes32(evmRecipient), { type: "bytes" }),
      new Address(USDC_SAC).toScVal(),
      nativeToScVal(Buffer.alloc(32), { type: "bytes" }), // any caller
      nativeToScVal(maxFee, { type: "i128" }),
      nativeToScVal(2000, { type: "u32" }),
      nativeToScVal(FORWARD_HOOK, { type: "bytes" }),
    ],
  );

  const message = await waitForAttestation(burnHash);
  console.log("Burn:", burnHash, "Forward state:", message.forwardState);
}

// 5 USDC in 7-decimal units
bridgeToBase(50_000_000n, "0xYourBaseSepoliaAddress").catch(console.error);
```

import math
import os
import time

import requests
from stellar_sdk import Keypair, Network, SorobanServer, TransactionBuilder, scval
from stellar_sdk.soroban_rpc import GetTransactionStatus, SendTransactionStatus

# Testnet values. For mainnet, use Circle's mainnet contract list,
# the mainnet USDC SAC, and https://iris-api.circle.com.
RPC_URL = "https://soroban-testnet.stellar.org"
IRIS_URL = "https://iris-api-sandbox.circle.com"
TOKEN_MESSENGER_MINTER = "CDNG7HXAPBWICI2E3AUBP3YZWZELJLYSB6F5CC7WLDTLTHVM74SLRTHP"
USDC_SAC = "CBIELTK6YBZJU5UP2WWQEUCYKLPU6AUNZ2BQ4WWFEIE3USCIHMXQDAMA"
STELLAR_DOMAIN = 27
BASE_DOMAIN = 6

server = SorobanServer(RPC_URL)
signer = Keypair.from_secret(os.environ["STELLAR_SECRET_KEY"])


def evm_address_to_bytes32(address: str) -> bytes:
    hex_str = address.lower().removeprefix("0x")
    if len(hex_str) != 40 or any(c not in "0123456789abcdef" for c in hex_str):
        raise ValueError(f"Invalid EVM address: {address}")
    return bytes.fromhex(hex_str.rjust(64, "0"))


def invoke(contract_id, method, args):
    account = server.load_account(signer.public_key)

    # Bid what recent transactions paid, capped at what you're willing to spend.
    # prepare_transaction adds the resource fee on top of this inclusion fee.
    # This Stellar network fee is paid in XLM, apart from Circle's max_fee.
    MAX_INCLUSION_FEE = 100_000  # stroops (0.01 XLM): pick your own cap
    fee = min(server.get_fee_stats().soroban_inclusion_fee.p90, MAX_INCLUSION_FEE)

    tx = (
        TransactionBuilder(account, Network.TESTNET_NETWORK_PASSPHRASE, base_fee=fee)
        .append_invoke_contract_function_op(contract_id, method, args)
        .set_timeout(60)
        .build()
    )

    prepared = server.prepare_transaction(tx)
    prepared.sign(signer)
    sent = server.send_transaction(prepared)
    if sent.status != SendTransactionStatus.PENDING:
        raise RuntimeError(f"Submit failed: {sent.status}")
    result = server.poll_transaction(sent.hash)
    if result.status == GetTransactionStatus.NOT_FOUND:
        # Not in a ledger yet: the outcome is unknown, not failed.
        raise RuntimeError(f"Transaction {sent.hash} not found yet")
    if result.status != GetTransactionStatus.SUCCESS:
        raise RuntimeError(f"Transaction failed: {result.status}")
    return sent.hash


def quote_max_fee(amount: int) -> int:
    res = requests.get(
        f"{IRIS_URL}/v2/burn/USDC/fees/{STELLAR_DOMAIN}/{BASE_DOMAIN}",
        params={"forward": "true"},
        timeout=30,
    )
    quote = next((q for q in res.json() if q["finalityThreshold"] == 2000), None)
    if quote is None:
        raise RuntimeError("No fee quote for finality threshold 2000")
    # The live API returns forwardFee.med. Circle's spec names it medium.
    forward_fee = quote["forwardFee"].get("med")
    if forward_fee is None:
        forward_fee = quote["forwardFee"]["medium"]
    # minimumFee is in basis points. forwardFee uses 6 decimals, so
    # multiply by 10 for Stellar's 7-decimal units.
    protocol_fee = amount * math.ceil(quote["minimumFee"] * 100) // 1_000_000
    return protocol_fee + int(forward_fee) * 10


def wait_for_attestation(tx_hash: str):
    while True:
        res = requests.get(
            f"{IRIS_URL}/v2/messages/{STELLAR_DOMAIN}",
            params={"transactionHash": tx_hash},
            timeout=30,
        )
        if res.ok:
            messages = res.json().get("messages") or []
            if messages and messages[0].get("status") == "complete":
                return messages[0]
        time.sleep(5)


def bridge_to_base(amount: int, evm_recipient: str):
    caller = signer.public_key
    max_fee = quote_max_fee(amount)

    # Transaction 1: let the TokenMessengerMinter pull `amount` USDC.
    sequence = server.get_latest_ledger().sequence
    invoke(
        USDC_SAC,
        "approve",
        [
            scval.to_address(caller),
            scval.to_address(TOKEN_MESSENGER_MINTER),
            scval.to_int128(amount),
            scval.to_uint32(sequence + 100),
        ],
    )

    # Transaction 2: burn with the forwarding hook.
    burn_hash = invoke(
        TOKEN_MESSENGER_MINTER,
        "deposit_for_burn_with_hook",
        [
            scval.to_address(caller),
            scval.to_int128(amount),
            scval.to_uint32(BASE_DOMAIN),
            scval.to_bytes(evm_address_to_bytes32(evm_recipient)),
            scval.to_address(USDC_SAC),
            scval.to_bytes(bytes(32)),  # any caller
            scval.to_int128(max_fee),
            scval.to_uint32(2000),
            scval.to_bytes(FORWARD_HOOK),
        ],
    )

    message = wait_for_attestation(burn_hash)
    print("Burn:", burn_hash, "Forward state:", message.get("forwardState"))


if __name__ == "__main__":
    # 5 USDC in 7-decimal units
    bridge_to_base(50_000_000, "0xYourBaseSepoliaAddress")

// "cctp-forward", hook version 0, no extra data:
// 0x636374702d666f72776172640000000000000000000000000000000000000000

var (

func evmAddressToBytes32(address string) ([]byte, error) {
  raw, err := hex.DecodeString(strings.TrimPrefix(strings.ToLower(address), "0x"))
  if err != nil || len(raw) != 20 {
    return nil, fmt.Errorf("invalid EVM address: %s", address)
  }
  return append(make([]byte, 12), raw...), nil
}

// ScVal helpers for the contract arguments.
func addressVal(address string) xdr.ScVal {
  var scAddress xdr.ScAddress
  if strings.HasPrefix(address, "C") {
    var contractID xdr.ContractId
    copy(contractID[:], strkey.MustDecode(strkey.VersionByteContract, address))
    scAddress = xdr.ScAddress{
      Type:       xdr.ScAddressTypeScAddressTypeContract,
      ContractId: &contractID,
    }
  } else {
    scAddress = xdr.ScAddress{
      Type:      xdr.ScAddressTypeScAddressTypeAccount,
      AccountId: xdr.MustAddressPtr(address),
    }
  }
  return xdr.ScVal{Type: xdr.ScValTypeScvAddress, Address: &scAddress}
}

func i128Val(amount int64) xdr.ScVal {
  // Sign-extend the int64 to 128 bits.
  parts := xdr.Int128Parts{Hi: xdr.Int64(amount >> 63), Lo: xdr.Uint64(amount)}
  return xdr.ScVal{Type: xdr.ScValTypeScvI128, I128: &parts}
}

func u32Val(value uint32) xdr.ScVal {
  v := xdr.Uint32(value)
  return xdr.ScVal{Type: xdr.ScValTypeScvU32, U32: &v}
}

func bytesVal(value []byte) xdr.ScVal {
  b := xdr.ScBytes(value)
  return xdr.ScVal{Type: xdr.ScValTypeScvBytes, Bytes: &b}
}

func invoke(ctx context.Context, contractID, method string, args []xdr.ScVal) (string, error) {
  account, err := server.LoadAccount(ctx, signer.Address())
  if err != nil {
    return "", err
  }

  // Bid what recent transactions paid, capped at what you're willing to spend.
  // prepareTransaction adds the resource fee on top of this inclusion fee.
  // This Stellar network fee is paid in XLM, apart from Circle's max_fee.
  feeStats, err := server.GetFeeStats(ctx)
  if err != nil {
    return "", err
  }
  const maxInclusionFee = 100_000 // stroops (0.01 XLM): pick your own cap
  fee := min(int64(feeStats.SorobanInclusionFee.P90), maxInclusionFee)

  tx, err := prepareTransaction(ctx, txnbuild.TransactionParams{
    SourceAccount:        account,
    IncrementSequenceNum: true,
    BaseFee:              fee,
    Preconditions:        txnbuild.Preconditions{TimeBounds: txnbuild.NewTimeout(60)},
    Operations: []txnbuild.Operation{&txnbuild.InvokeHostFunction{
      HostFunction: xdr.HostFunction{
        Type: xdr.HostFunctionTypeHostFunctionTypeInvokeContract,
        InvokeContract: &xdr.InvokeContractArgs{
          ContractAddress: *addressVal(contractID).Address,
          FunctionName:    xdr.ScSymbol(method),
          Args:            args,
        },
      },
    }},
  })
  if err != nil {
    return "", err
  }

  tx, err = tx.Sign(network.TestNetworkPassphrase, signer)
  if err != nil {
    return "", err
  }
  envelope, err := tx.Base64()
  if err != nil {
    return "", err
  }
  sent, err := server.SendTransaction(ctx, protocol.SendTransactionRequest{Transaction: envelope})
  if err != nil {
    return "", err
  }
  if sent.Status != "PENDING" {
    return "", fmt.Errorf("submit failed: %s", sent.Status)
  }

  // PollTransaction keeps polling until the context times out.
  pollCtx, cancel := context.WithTimeout(ctx, 30*time.Second)
  defer cancel()
  result, err := server.PollTransaction(pollCtx, sent.Hash)
  if errors.Is(err, context.DeadlineExceeded) {
    // Not in a ledger yet: the outcome is unknown, not failed.
    return "", fmt.Errorf("transaction %s not found yet", sent.Hash)
  }
  if err != nil {
    return "", err
  }
  if result.Status != protocol.TransactionStatusSuccess {
    return "", fmt.Errorf("transaction failed: %s", result.Status)
  }
  return sent.Hash, nil
}

// prepareTransaction simulates the transaction, then builds it again with the
// simulated resources, resource fee, and authorization entries. The Go SDK has
// no prepareTransaction.
func prepareTransaction(ctx context.Context, params txnbuild.TransactionParams) (*txnbuild.Transaction, error) {
  tx, err := txnbuild.NewTransaction(params)
  if err != nil {
    return nil, err
  }
  envelope, err := tx.Base64()
  if err != nil {
    return nil, err
  }
  sim, err := server.SimulateTransaction(ctx, protocol.SimulateTransactionRequest{Transaction: envelope})
  if err != nil {
    return nil, err
  }
  if sim.Error != "" {
    return nil, fmt.Errorf("simulation failed: %s", sim.Error)
  }

  var sorobanData xdr.SorobanTransactionData
  if err := xdr.SafeUnmarshalBase64(sim.TransactionDataXDR, &sorobanData); err != nil {
    return nil, err
  }
  operation := params.Operations[0].(*txnbuild.InvokeHostFunction)
  operation.Ext = xdr.TransactionExt{V: 1, SorobanData: &sorobanData}
  if len(sim.Results) > 0 && sim.Results[0].AuthXDR != nil {
    for _, entryXDR := range *sim.Results[0].AuthXDR {
      var entry xdr.SorobanAuthorizationEntry
      if err := xdr.SafeUnmarshalBase64(entryXDR, &entry); err != nil {
        return nil, err
      }
      operation.Auth = append(operation.Auth, entry)
    }
  }

  // Build again with the same sequence number. NewTransaction adds the
  // resource fee from the Soroban data to the inclusion fee.
  source := tx.SourceAccount()
  params.SourceAccount = &source
  params.IncrementSequenceNum = false
  return txnbuild.NewTransaction(params)
}

func quoteMaxFee(amount int64) (int64, error) {
  res, err := httpClient.Get(fmt.Sprintf(
    "%s/v2/burn/USDC/fees/%d/%d?forward=true", irisURL, stellarDomain, baseDomain,
  ))
  if err != nil {
    return 0, err
  }
  defer res.Body.Close()
  if res.StatusCode != http.StatusOK {
    return 0, fmt.Errorf("fee quote failed: %s", res.Status)
  }

  var quotes []struct {
    FinalityThreshold int     `json:"finalityThreshold"`
    MinimumFee        float64 `json:"minimumFee"`
    ForwardFee        struct {
      Med    *int64 `json:"med"`
      Medium *int64 `json:"medium"`
    } `json:"forwardFee"`
  }
  if err := json.NewDecoder(res.Body).Decode(&quotes); err != nil {
    return 0, err
  }
  for _, quote := range quotes {
    if quote.FinalityThreshold != 2000 {
      continue
    }
    // The live API returns forwardFee.med. Circle's spec names it medium.
    forwardFee := quote.ForwardFee.Med
    if forwardFee == nil {
      forwardFee = quote.ForwardFee.Medium
    }
    if forwardFee == nil {
      return 0, errors.New("no forwardFee in the fee quote")
    }
    // minimumFee is in basis points. forwardFee uses 6 decimals, so
    // multiply by 10 for Stellar's 7-decimal units.
    protocolFee := amount * int64(math.Ceil(quote.MinimumFee*100)) / 1_000_000
    return protocolFee + *forwardFee*10, nil
  }
  return 0, errors.New("no fee quote for finality threshold 2000")
}

type cctpMessage struct {
  Status       string `json:"status"`
  ForwardState string `json:"forwardState"`
}

func waitForAttestation(txHash string) (cctpMessage, error) {
  url := fmt.Sprintf("%s/v2/messages/%d?transactionHash=%s", irisURL, stellarDomain, txHash)
  for {
    res, err := httpClient.Get(url)
    if err != nil {
      return cctpMessage{}, err
    }
    var body struct {
      Messages []cctpMessage `json:"messages"`
    }
    decodeErr := json.NewDecoder(res.Body).Decode(&body)
    res.Body.Close()
    if res.StatusCode == http.StatusOK && decodeErr == nil &&
      len(body.Messages) > 0 && body.Messages[0].Status == "complete" {
      return body.Messages[0], nil
    }
    time.Sleep(5 * time.Second)
  }
}

func bridgeToBase(ctx context.Context, amount int64, evmRecipient string) error {
  caller := signer.Address()
  maxFee, err := quoteMaxFee(amount)
  if err != nil {
    return err
  }
  mintRecipient, err := evmAddressToBytes32(evmRecipient)
  if err != nil {
    return err
  }

  // Transaction 1: let the TokenMessengerMinter pull `amount` USDC.
  latest, err := server.GetLatestLedger(ctx)
  if err != nil {
    return err
  }
  _, err = invoke(ctx, usdcSAC, "approve", []xdr.ScVal{
    addressVal(caller),
    addressVal(tokenMessengerMinter),
    i128Val(amount),
    u32Val(latest.Sequence + 100),
  })
  if err != nil {
    return err
  }

  // Transaction 2: burn with the forwarding hook.
  burnHash, err := invoke(ctx, tokenMessengerMinter, "deposit_for_burn_with_hook", []xdr.ScVal{
    addressVal(caller),
    i128Val(amount),
    u32Val(baseDomain),
    bytesVal(mintRecipient),
    addressVal(usdcSAC),
    bytesVal(make([]byte, 32)), // any caller
    i128Val(maxFee),
    u32Val(2000),
    bytesVal(forwardHook),
  })
  if err != nil {
    return err
  }

  message, err := waitForAttestation(burnHash)
  if err != nil {
    return err
  }
  fmt.Println("Burn:", burnHash, "Forward state:", message.ForwardState)
  return nil
}

func main() {
  defer server.Close()
  // 5 USDC in 7-decimal units
  if err := bridgeToBase(context.Background(), 50_000_000, "0xYourBaseSepoliaAddress"); err != nil {
    log.Fatal(err)
  }
}

`forwardState` can stay empty for a short time after the attestation completes. Check the same endpoint again to see the destination transaction in `forwardTxHash`.

To mint it yourself instead, call `deposit_for_burn` without `hook_data`, set `max_fee` from the quote without `forward=true`, and call `receiveMessage(message, attestation)` on the destination chain's `MessageTransmitterV2`. Do not call `deposit_for_burn_with_hook` with empty `hook_data`, because the contract rejects it.
