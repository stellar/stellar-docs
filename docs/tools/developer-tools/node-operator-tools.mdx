# Node Operator Tools

### [Stellar Archivist](https://github.com/stellar/rs-stellar-archivist)

A command line tool for scanning, repairing, and mirroring Stellar Core history archives. See [Publishing History Archives](../../validators/admin-guide/publishing-history-archives.mdx#complete-history-archive) for usage.

### [Go SDK Tools](https://github.com/stellar/go-stellar-sdk/tree/master/tools)

A GitHub repository with tools like Horizon cmp (compares responses of two Horizon servers).
