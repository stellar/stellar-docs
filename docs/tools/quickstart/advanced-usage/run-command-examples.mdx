---
title: Run Commands
description: Examples of run commands for starting Quickstart in the different modes
---

Below is a list of various ways you might want to run the Quickstart container annotated to illustrate what options are enabled. It's also recommended that you should learn and get familiar with the docker command. Start an ephemeral local-only dev/test network:

<Tabs>

<Tab title="macOS/Linux">

```sh
docker run -d \
  -p "8000:8000" \
  --name stellar \
  stellar/quickstart \
  --local
```

</Tab>

<Tab title="Windows (PowerShell)">

```powershell
docker run -d `
  -p "8000:8000" `
  --name stellar `
  stellar/quickstart `
  --local
```

</Tab>

</Tabs>

Start an ephemeral testnet node in the foreground:

<Tabs>

<Tab title="macOS/Linux">

```sh
docker run --rm -it \
  -p "8000:8000" \
  --name stellar \
  stellar/quickstart \
  --testnet
```

</Tab>

<Tab title="Windows (PowerShell)">

```powershell
docker run --rm -it `
  -p "8000:8000" `
  --name stellar `
  stellar/quickstart `
  --testnet
```

</Tab>

</Tabs>

Start a new persistent node using the host directory `/str`:

<Tabs>

<Tab title="macOS/Linux">

```sh
docker run -it --rm \
  -p "8000:8000" \
  -v "/str:/opt/stellar" \
  --name stellar \
  stellar/quickstart \
  --testnet
```

</Tab>

<Tab title="Windows (PowerShell)">

```powershell
docker run -it --rm `
  -p "8000:8000" `
  -v "/str:/opt/stellar" `
  --name stellar `
  stellar/quickstart `
  --testnet
```

</Tab>

</Tabs>

Start an ephemeral local network with manual ledger close enabled. Ledgers only advance when you send the `manualclose` command to stellar-core's HTTP endpoint (see [Operation Modes](./operation-modes)):

<Tabs>

<Tab title="macOS/Linux">

```sh
docker run -d \
  -p "8000:8000" \
  -p "127.0.0.1:11626:11626" \
  --name stellar \
  stellar/quickstart \
  --local \
  --enable-core-manual-close
```

</Tab>

<Tab title="Windows (PowerShell)">

```powershell
docker run -d `
  -p "8000:8000" `
  -p "127.0.0.1:11626:11626" `
  --name stellar `
  stellar/quickstart `
  --local `
  --enable-core-manual-close
```

</Tab>

</Tabs>
