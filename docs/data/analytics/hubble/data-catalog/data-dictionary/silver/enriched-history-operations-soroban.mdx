## Column Details

Column details are equivalent to the silver [Enriched History Operations](./enriched-history-operations.mdx) table. Filters down to only operation types 24, 25, and 26.

One column differs. This model selects `enriched.type as op_type`, so the operation type code is named `op_type` here and `type` on the Enriched History Operations page:

| Name | Description | Data Type | Domain Values | Required? | Notes |
| --- | --- | --- | --- | --- | --- |
| op_type | The number indicating which type of operation this operation executes. | INTEGER | <ul><li>24 - invoke_host_function</li><li>25 - extend_footprint_ttl</li><li>26 - restore_footprint</li></ul> | Yes | Cluster Field. Named `type` on the Enriched History Operations table. |
