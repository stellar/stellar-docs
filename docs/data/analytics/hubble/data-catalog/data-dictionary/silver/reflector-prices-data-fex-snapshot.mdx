## Table Metadata

| Property | Configuration |
| --- | --- |
| Natural Key(s) | asset_code, valid_from |
| Partition Field(s) | N/A |
| Clustered Field(s) | asset_code |
| Documentation | [dbt docs](http://www.stellar-dbt-docs.com/#!/model/model.stellar_dbt_public.reflector_prices_data_fex_snapshot) |

This table captures historical snapshots of the exchange price of fiat currencies (foreign exchange). Prices originate from the [Reflector](https://reflector.network/) oracle contracts on Stellar. The `valid_from` and `valid_to` timestamps identify when each record was active.

## Column Details

| Name | Description | Data Type | Domain Values | Required? | Notes |
| --- | --- | --- | --- | --- | --- |
| day | The day when the asset price is valid. | DATE |  | Yes |  |
| asset_code | The 4 or 12 character code representation of the asset on the network. | STRING |  | Yes | Natural Key. Cluster Field. |
| open_usd | Price of the asset in USD at the start of the day. | FLOAT |  | Yes |  |
| high_usd | Highest price of the asset in USD during the day. | FLOAT |  | Yes |  |
| low_usd | Lowest price of the asset in USD during the day. | FLOAT |  | Yes |  |
| close_usd | Price of the asset in USD at the end of the day. | FLOAT |  | Yes |  |
| valid_from | The timestamp when this snapshot row was first inserted and became effective. This helps in tracking changes over time. | TIMESTAMP |  | Yes | Natural Key. |
| valid_to | The timestamp when this row is no longer valid. If `null`, the record is currently active. | TIMESTAMP |  | No |  |
