title: The Path Object
description: "When Horizon returns information about a path, it uses the following format."
---

When Horizon returns information about a path, it uses the following format:

<ResponseField name="source_asset_type" type="string">

The type for the source asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.

</ResponseField>

<ResponseField name="source_asset_code" type="string">

The code for the source asset.

</ResponseField>

<ResponseField name="source_asset_issuer" type="string">

The Stellar address of the source asset’s issuer.

</ResponseField>

<ResponseField name="source_amount" type="string">

An estimated cost for making a payment of destination_amount on this path. Suitable for use in the `sendMax` field of a path payment operation.

</ResponseField>

<ResponseField name="destination_asset_type" type="string">

The type for the destination asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.

</ResponseField>

<ResponseField name="destination_asset_code" type="string">

The code for the destination asset.

</ResponseField>

<ResponseField name="destination_asset_issuer" type="string">

The Stellar address of the destination asset’s issuer.

</ResponseField>

<ResponseField name="destination_amount" type="string">

The destination amount specified in the search that found this path.

</ResponseField>

<ResponseField name="path" type="array of objects">

The intermediary assets that this path hops through.

  <Expandable title="path properties">
    <ResponseField name="asset_code" type="string">

      The code for this intermediary asset.

    </ResponseField>

    <ResponseField name="asset_issuer" type="string">

      The Stellar address of the intermediary asset’s issuer.

    </ResponseField>

    <ResponseField name="asset_type" type="string">

      The type for the intermediary asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.

    </ResponseField>

  </Expandable>
</ResponseField>
