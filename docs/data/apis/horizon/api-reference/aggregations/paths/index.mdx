---
title: Paths
description: "Paths provide information about potential path payments. A path can be used to populate the necessary fields for a path payment operation."
---

The [latest ledger](/docs/data/apis/horizon/api-reference/structure/consistency) known to Horizon is included as an HTTP header in the response.

Learn more about the two types of path payment: [`path payment strict send`](/docs/learn/fundamentals/transactions/list-of-operations#path-payment-strict-send) and [`path payment strict receive`](/docs/learn/fundamentals/transactions/list-of-operations#path-payment-strict-receive)

| --- | --- |
| GET | [/paths/strict-receive](/docs/data/apis/horizon/api-reference/list-strict-receive-payment-paths) |
| GET | [/paths/strict-send](/docs/data/apis/horizon/api-reference/list-strict-send-payment-paths) |
