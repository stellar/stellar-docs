---
title: The Order Book Object
description: "When Horizon returns information about an order book, it uses the following format."
---

When Horizon returns information about an order book, it uses the following format:

<ResponseField name="bids" type="object">
  The prices and amounts for the buyside of the asset pair.

  <Expandable title="bids properties">
    <ResponseField name="price_r" type="object">
      A precise representation of the bid price of the asset pair.

      <Expandable title="price_r properties">
        <ResponseField name="n" type="number">
          The numerator.
        </ResponseField>

        <ResponseField name="d" type="number">
          The denominator.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="price" type="string">
      The bid price of the base asset denominated in the counter asset. A number representing the decimal form of `price_r`.
    </ResponseField>

    <ResponseField name="amount" type="string">
      The amount of counter asset that the account making this offer is willing to buy at this price.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="asks" type="object">
  The prices and amounts for the sellside of the asset pair.

  <Expandable title="asks properties">
    <ResponseField name="price_r" type="object">
      A precise representation of the ask price of the asset pair.

      <Expandable title="price_r properties">
        <ResponseField name="n" type="number">
          The numerator.
        </ResponseField>

        <ResponseField name="d" type="number">
          The denominator.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="price" type="string">
      The ask price of the base asset denominated in the counter asset. A number representing the decimal form of `price_r`.
    </ResponseField>

    <ResponseField name="amount" type="string">
      The amount of counter asset that the account making this offer is willing to sell at this price.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="base" type="object">
  Details about the base asset.

  <Expandable title="base properties">
    <ResponseField name="asset_type" type="string">
      The type for the base asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.
    </ResponseField>

    <ResponseField name="asset_code" type="string">
      The code for the base asset.
    </ResponseField>

    <ResponseField name="asset_issuer" type="string">
      The Stellar address of the base asset’s issuer.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="counter" type="object">
  Details about the counter asset.

  <Expandable title="counter properties">
    <ResponseField name="asset_type" type="string">
      The type for the counter asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.
    </ResponseField>

    <ResponseField name="asset_code" type="string">
      The code for the counter asset.
    </ResponseField>

    <ResponseField name="asset_issuer" type="string">
      The Stellar address of the counter asset’s issuer.
    </ResponseField>
  </Expandable>
</ResponseField>

The [latest ledger](../../structure/consistency) known to Horizon is included as an HTTP header in the response.
