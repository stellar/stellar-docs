Stellar uses conventional HTTP response codes to indicate the success or failure of an API request. In general:

- Codes in the 2xx range indicate success.
- Codes in the 4xx range indicate an error that failed given the information provided
- Codes in the 5xx range indicate an error with the Horizon server.

There are two types of Status Codes: [Standard Status Codes](/docs/data/apis/horizon/api-reference/errors/http-status-codes/standard) and [Horizon-Specific Status Codes](/docs/data/apis/horizon/api-reference/errors/http-status-codes/horizon-specific).

| HTTP Status Code Types |  |
| --- | --- |
| [Standard Status Codes](/docs/data/apis/horizon/api-reference/errors/http-status-codes/standard) | Generic HTTP responses. |
| [Horizon-Specific Status Codes](/docs/data/apis/horizon/api-reference/errors/http-status-codes/horizon-specific) | Errors that are unique to Horizon. |
