These responses are Internet protocol codes that describe basic issues with a submitted transaction.

<ResponseField name="OK" type="200">

The request has succeeded.

</ResponseField>

<ResponseField name="Bad Request" type="400">

The request as invalid in some way.

</ResponseField>

<ResponseField name="Not Found" type="404">

The requested resource does not exist.

</ResponseField>

<ResponseField name="Not Implemented" type="404">

The request does not have an acceptable response content-type.

</ResponseField>

<ResponseField name="Not Acceptable" type="406">

The request does not have an acceptable response content-type.

</ResponseField>

<ResponseField name="Internal Server Error" type="500">

Something went wrong on the Horizon server’s end.

</ResponseField>

```json Example Response for a Bad Request Status Code
{
  "type": "https://stellar.org/horizon-errors/bad_request",
  "title": "Bad Request",
  "status": 400,
  "detail": "The request you sent was invalid in some way",
  "extras": {
    "invalid_field": "limit",
    "reason": "unparseable value"
  }
}
```
