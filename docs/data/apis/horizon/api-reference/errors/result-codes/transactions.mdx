These are Result Codes that communicate success (200) or failure (400) at the transaction level: bad sequence numbers, insufficient balances, insufficient fees, etc.

<ResponseField name="RESULT CODE" type="STELLAR PROTOCOL CODE">

Description

</ResponseField>

<ResponseField name="tx_success" type="txSUCCESS">

The transaction succeeded.

</ResponseField>

<ResponseField name="tx_failed" type="txFAILED">

One of the operations failed (none were applied).

</ResponseField>

<ResponseField name="tx_too_early" type="txTOO_EARLY">

The ledger closeTime was before the minTime.

</ResponseField>

<ResponseField name="tx_too_late" type="txTOO_LATE">

The ledger closeTime was after the maxTime.

</ResponseField>

<ResponseField name="tx_missing_operation" type="txMISSING_OPERATION">

No operation was specified

</ResponseField>

<ResponseField name="tx_bad_seq" type="txBAD_SEQ">

sequence number does not match source account

</ResponseField>

<ResponseField name="tx_bad_auth" type="txBAD_AUTH">

too few valid signatures / wrong network

</ResponseField>

<ResponseField name="tx_insufficient_balance" type="txINSUFFICIENT_BALANCE">

fee would bring account below reserve

</ResponseField>

<ResponseField name="tx_no_source_account" type="txNO_ACCOUNT">

source account not found

</ResponseField>

<ResponseField name="tx_insufficient_fee" type="txINSUFFICIENT_FEE">

fee is too small

</ResponseField>

<ResponseField name="tx_bad_auth_extra" type="txBAD_AUTH_EXTRA">

unused signatures attached to transaction

</ResponseField>

<ResponseField name="tx_internal_error" type="txINTERNAL_ERROR">

an unknown error occurred

</ResponseField>
