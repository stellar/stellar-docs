These are result codes that communicate success (200) or failure (400) specific to the `Set Options` operation.

Learn more about the [`Set Options` operation](../../../../../../../learn/fundamentals/transactions/list-of-operations#set-options).

<ResponseField name="OpSuccess" type="SET_OPTIONS_SUCCESS">

Options successfully set.

</ResponseField>

<ResponseField name="OpLowReserve" type="SET_OPTIONS_LOW_RESERVE">

This account does not have enough XLM to satisfy the minimum XLM reserve increase caused by adding a subentry and still satisfy its XLM selling liabilities. For every new signer added to an account, the minimum reserve of XLM that account must hold increases.

</ResponseField>

<ResponseField name="op_too_many_signers" type="SET_OPTIONS_TOO_MANY_SIGNERS">

20 is the maximum number of signers an account can have, and adding another signer would exceed that.

</ResponseField>

<ResponseField name="op_bad_flags" type="SET_OPTIONS_BAD_FLAGS">

The flags set and/or cleared are invalid by themselves or in combination.

</ResponseField>

<ResponseField name="op_invalid_inflation" type="SET_OPTIONS_INVALID_INFLATION">

The destination account set in the inflation field does not exist.

</ResponseField>

<ResponseField name="op_cant_change" type="SET_OPTIONS_CANT_CHANGE">

This account can no longer change the option it wants to change.

</ResponseField>

<ResponseField name="op_unknown_flag" type="SET_OPTIONS_UNKNOWN_FLAG">

The account is trying to set a flag that is unknown.

</ResponseField>

<ResponseField name="op_threshold_out_of_range" type="SET_OPTIONS_THRESHOLD_OUT_OF_RANGE">

The value for a key weight or threshold is invalid.

</ResponseField>

<ResponseField name="op_bad_signer" type="SET_OPTIONS_BAD_SIGNER">

Any additional signers added to the account cannot be the master key.

</ResponseField>

<ResponseField name="op_invalid_home_domain" type="SET_OPTIONS_INVALID_HOME_DOMAIN">

Home domain is malformed.

</ResponseField>
