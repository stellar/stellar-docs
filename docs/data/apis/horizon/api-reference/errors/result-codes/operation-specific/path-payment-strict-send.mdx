These are result codes that communicate success (200) or failure (400) specific to the `Path Payment Strict Send` operation.

Learn more about the [`Path Payment Strict Send` operation](../../../../../../../learn/fundamentals/transactions/list-of-operations#path-payment-strict-send).

<ResponseField name="OpSuccess" type="PATH_PAYMENT_STRICT_SEND_SUCCESS">

The payment was successfully completed.

</ResponseField>

<ResponseField name="OpMalformed" type="PATH_PAYMENT_STRICT_SEND_MALFORMED">

The input for this path payment is invalid.

</ResponseField>

<ResponseField name="OpUnderfunded" type="PATH_PAYMENT_STRICT_SEND_UNDERFUNDED">

The source account (sender) does not have enough lumens to send the payment amount while maintaining its own minimum reserve.

</ResponseField>

<ResponseField name="OpSrcNoTrust" type="PATH_PAYMENT_STRICT_SEND_SRC_NO_TRUST">

The source account is missing the appropriate trustline.

</ResponseField>

<ResponseField name="OpSrcNotAuthorized" type="PATH_PAYMENT_STRICT_SEND_SRC_NOT_AUTHORIZED">

The source account is not authorized to send this asset.

</ResponseField>

<ResponseField name="OpNoDestination" type="PATH_PAYMENT_STRICT_SEND_NO_DESTINATION">

The destination account does not exist.

</ResponseField>

<ResponseField name="OpNoTrust" type="PATH_PAYMENT_STRICT_SEND_NO_TRUST">

The destination account does not have a trustline for the asset being sent.

</ResponseField>

<ResponseField name="OpNotAuthorized" type="PATH_PAYMENT_STRICT_SEND_NOT_AUTHORIZED">

The destination account is not authorized to hold this asset.

</ResponseField>

<ResponseField name="OpLineFull" type="PATH_PAYMENT_STRICT_SEND_LINE_FULL">

The destination account (receiver) does not have sufficient limits to receive amount and still satisfy its buying liabilities.

</ResponseField>

<ResponseField name="OpNoIssuer" type="PATH_PAYMENT_STRICT_SEND_NO_ISSUER">

The issuer of one of the assets is missing.

</ResponseField>

<ResponseField name="OpTooFewOffers" type="PATH_PAYMENT_STRICT_SEND_TOO_FEW_OFFERS">

There is no path of offers connecting the send asset and destination asset. Stellar only considers paths of length 5 or shorter.

</ResponseField>

<ResponseField name="OpCrossSelf" type="PATH_PAYMENT_STRICT_SEND_OFFER_CROSS_SELF">

This path payment would cross one of its own offers.

</ResponseField>

<ResponseField name="OpUnderDestMin" type="PATH_PAYMENT_STRICT_SEND_UNDER_DESTMIN">

The paths that could send destination amount of destination asset would fall short of destination min.

</ResponseField>
