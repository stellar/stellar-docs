<Note>
**Offer Lifecycle**

Although offer identifiers were [historically defined](https://github.com/stellar/stellar-horizon/blob/main/internal/db2/history/main.go#L114-L122), [manage_offer](../../../../../../learn/fundamentals/transactions/list-of-operations#manage-sell-offer)'s effects don't have ingestion code. To view them, decode the transaction's [`result_xdr`](../../structure/xdr), which contains the `ManageOfferSuccessResult`.

Use [List All Offers](/docs/data/apis/horizon/api-reference/get-all-offers) to inspect currently open offers and [Retrieve an Offer's Trades](/docs/data/apis/horizon/api-reference/get-trades-by-offer-id) for retained trade history associated with an offer.
</Note>
