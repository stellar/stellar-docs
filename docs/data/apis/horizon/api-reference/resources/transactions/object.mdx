<Info>

Transaction meta `result_meta_xdr` will be removed from the SDF hosted Horizon API (`horizon.stellar.org`) in Q3 2024. Instead of using Horizon to access transaction metadata, developers could access it with the [`getTransactions`](../../../../rpc/api-reference/methods/getTransactions) endpoint in the Stellar RPC.

</Info>

When Horizon returns information about a transaction, it uses the following format:

<ResponseField name="id" type="string">

A unique identifier for this transaction.

</ResponseField>

<ResponseField name="paging_token" type="number">

A cursor value for use in [pagination](/docs/data/apis/horizon/api-reference/structure/pagination).

</ResponseField>

<ResponseField name="successful" type="boolean">

Indicates if this transaction was successful or not.

</ResponseField>

<ResponseField name="hash" type="string">

A hex-encoded SHA-256 hash of this transaction’s [XDR](../../../../../../learn/fundamentals/data-format/xdr)-encoded form.

</ResponseField>

<ResponseField name="ledger" type="number">

The sequence number of the ledger that this transaction was included in.

</ResponseField>

<ResponseField name="created_at" type="ISO8601 string">

The date this transaction was created.

</ResponseField>

<ResponseField name="source_account" type="string">

The account that originates the transaction.

</ResponseField>

<ResponseField name="source_account_sequence" type="string">

The source account's sequence number that this transaction consumed.

</ResponseField>

<ResponseField name="fee_charged" type="number">

The fee (in [stroops](../../../../../../learn/fundamentals/lumens)) paid by the source account to apply this transaction to the ledger.

</ResponseField>

<ResponseField name="max_fee" type="number">

The maximum fee (in [stroops](../../../../../../learn/fundamentals/lumens)) that the source account was willing to pay.

</ResponseField>

<ResponseField name="operation_count" type="number">

The number of operations contained within this transaction.

</ResponseField>

<ResponseField name="envelope_xdr" type="string">

A base64 encoded string of the raw `TransactionEnvelope` XDR struct for this transaction.

</ResponseField>

<ResponseField name="result_xdr" type="string">

A base64 encoded string of the raw `TransactionResult` XDR struct for this transaction.

</ResponseField>

<ResponseField name="result_meta_xdr" type="string">

**_[To be deprecated in Q3]_** A base64 encoded string of the raw `TransactionMeta` XDR struct for this transaction

</ResponseField>

<ResponseField name="fee_meta_xdr" type="string">

A base64 encoded string of the raw `LedgerEntryChanges` XDR struct produced by taking fees for this transaction.

</ResponseField>

<ResponseField name="memo" type="string">

The optional memo attached to a transaction.

</ResponseField>

<ResponseField name="memo_type" type="string">

The type of memo. Potential values include `MEMO_TEXT`, `MEMO_ID`, `MEMO_HASH`, `MEMO_RETURN`.

</ResponseField>

<ResponseField name="signatures" type="string">

An array of signatures used to sign this transaction.

</ResponseField>

<ResponseField name="preconditions" type="object">

A set of transaction preconditions affecting its validity.

  <Expandable title="preconditions properties">
    <ResponseField name="time_bounds" type="object">

      The time range for which this transaction is valid, with bounds as unsigned 64-bit UNIX timestamps

      <Expandable title="time_bounds properties">
        <ResponseField name="min_time" type="string">

          the lower bound

        </ResponseField>

        <ResponseField name="max_time" type="string">

          the upper bound

        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="ledger_bounds" type="object">

      The ledger range for which this transaction is valid, as unsigned 32-bit integers.

      <Expandable title="ledger_bounds properties">
        <ResponseField name="min_ledger" type="number">

          the lower bound

        </ResponseField>

        <ResponseField name="max_ledger" type="number">

          the upper bound

        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="min_account_sequence" type="string">

      Containing a positive, signed 64-bit integer representing the lowest source account sequence number for which the transaction is valid.

    </ResponseField>

    <ResponseField name="min_account_sequence_age" type="number">

      The minimum duration of time (in seconds as an unsigned 64-bit integer) that must have passed since the source account's sequence number changed for the transaction to be valid.

    </ResponseField>

    <ResponseField name="min_account_sequence_ledger_gap" type="number">

      An unsigned 32-bit integer representing the minimum number of ledgers that must have closed since the source account's sequence number changed for the transaction to be valid.

    </ResponseField>

    <ResponseField name="extra_signers" type="array of strings">

      The list of up to two additional signers that must have corresponding signatures for this transaction to be valid.

    </ResponseField>

  </Expandable>
</ResponseField>
