When Horizon returns information about an asset, it uses the following format:

<ResponseField name="asset_type" type="string">
  This asset's type. Either `credit_alphanum4` or `credit_alphanum12`.
</ResponseField>

<ResponseField name="asset_code" type="string">
  This asset's code
</ResponseField>

<ResponseField name="asset_issuer" type="string">
  The Stellar address of this asset’s issuer.
</ResponseField>

<ResponseField name="accounts" type="object">
  The number of accounts grouped by each trustline flag state.
</ResponseField>

<ResponseField name="num_claimable_balances" type="number">
  The current number of claimable_balances for this asset.
</ResponseField>

<ResponseField name="num_contracts" type="number">
  The current number of Soroban contracts holding this asset.
</ResponseField>

<ResponseField name="num_liquidity_pools" type="number">
  The current number of liquidity pools holding this asset.
</ResponseField>

<ResponseField name="balances" type="object">
  The number of units issued for this asset grouped by each trustline flag state.
</ResponseField>

<ResponseField name="claimable_balances_amount" type="string">
  The number of units for this asset held by all claimable balances.
</ResponseField>

<ResponseField name="contracts_amount" type="string">
  The number of units for this asset held by all Soroban contracts.
</ResponseField>

<ResponseField name="liquidity_pools_amount" type="string">
  The number of units for this asset held by all liquidity pools.
</ResponseField>

<ResponseField name="flags" type="object">
  Flags denote the enabling/disabling of certain asset issuer privileges.

  <Expandable title="flags properties">
    <ResponseField name="auth_immutable" type="boolean">
      If set to `true`, none of the following flags can be changed.
    </ResponseField>

    <ResponseField name="auth_required" type="boolean">
      If set to `true`, anyone who wants to hold an asset issued by this account must first be approved by this account.
    </ResponseField>

    <ResponseField name="auth_revocable" type="boolean">
      If set to `true`, this account can freeze the balance of a holder of an asset issued by this account.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="paging_token" type="number">
  A cursor value for use in [pagination](/docs/data/apis/horizon/api-reference/structure/pagination).
</ResponseField>

The [latest ledger](../../structure/consistency) known to Horizon is included as an HTTP header in the response.
