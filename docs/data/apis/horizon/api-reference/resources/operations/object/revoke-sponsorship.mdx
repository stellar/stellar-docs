---

Revoke sponsorship of a ledger entry.

<ResponseField name="account_id" type="string (optional)">

The id of the account which is no longer sponsored.

</ResponseField>

<ResponseField name="claimable_balance_id" type="string (optional)">

The id of the claimable balance which is no longer sponsored.

</ResponseField>

<ResponseField name="data_account_id" type="string (optional)">

The id of the account whose data entry is no longer sponsored.

</ResponseField>

<ResponseField name="data_name" type="string (optional)">

The name of the data entry which is no longer sponsored.

</ResponseField>

<ResponseField name="offer_id" type="string (optional)">

The id of the offer which is no longer sponsored.

</ResponseField>

<ResponseField name="trustline_account_id" type="string (optional)">

The id of the account whose trustline is no longer sponsored.

</ResponseField>

<ResponseField name="trustline_asset" type="string (optional)">

The asset of the trustline which is no longer sponsored.

</ResponseField>

<ResponseField name="signer_account_id" type="string (optional)">

The account id of the signer which is no longer sponsored.

</ResponseField>

<ResponseField name="signer_key" type="string (optional)">

The type of the signer which is no longer sponsored.

</ResponseField>
