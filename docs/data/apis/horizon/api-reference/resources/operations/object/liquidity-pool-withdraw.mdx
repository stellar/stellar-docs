Withdraws asset reserves from a liquidity pool by redeeming pool shares.

See the [`Liquidity Pool Withdraw` operation](../../../../../../../learn/fundamentals/transactions/list-of-operations#liquidity-pool-withdraw) for parameters, errors, etc.

<ResponseField name="liquidity_pool_id" type="string">

The liquidity pool associated with this withdrawal

</ResponseField>

<ResponseField name="reserves_min" type="array">

An array of objects corresponding to the minimum amount of each reserve that should've been withdrawn

  <Expandable title="reserves_min properties">
    <ResponseField name="asset" type="string">

      The asset in canonical (`Code:Issuer`) form

    </ResponseField>

    <ResponseField name="amount" type="string">

      A floating point value encoded as a string

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="shares" type="string">

The number of shares that were redeemed for this withdrawal operation

</ResponseField>

<ResponseField name="reserves_received" type="array">

An array of objects representing how much of each reserve ended up actually withdrawn from the pool

  <Expandable title="reserves_received properties">
    <ResponseField name="asset" type="string">

      The asset in canonical (`Code:Issuer`) form

    </ResponseField>

    <ResponseField name="amount" type="string">

      A floating point value encoded as a string

    </ResponseField>

  </Expandable>
</ResponseField>
