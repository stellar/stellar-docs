See the [generic Operation errors](/docs/data/apis/horizon/api-reference/errors/result-codes/operations).

<ResponseField name="id" type="number">

The operation's ID number.

</ResponseField>

<ResponseField name="paging_token" type="string">

A cursor value for use in [pagination](/docs/data/apis/horizon/api-reference/structure/pagination).

</ResponseField>

<ResponseField name="type_i" type="number">

A number indicating the operation type.

</ResponseField>

<ResponseField name="type" type="string">

The name of the operation type.

</ResponseField>

<ResponseField name="transaction_hash" type="string">

A unique identifier for the transaction this operation belongs to.

</ResponseField>

<ResponseField name="transaction_successful" type="boolean">

Indicates if this operation was part of a successful transaction.

</ResponseField>

<ResponseField name="source_account" type="string">

The account that originates the operation.

</ResponseField>

<ResponseField name="created_at" type="string">

The date this operation was created.

</ResponseField>
