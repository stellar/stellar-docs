When Horizon returns information about an offer, it uses the following format:

<ResponseField name="id" type="string">

A unique identifier for this offer.

</ResponseField>

<ResponseField name="paging_token" type="number">

A cursor value for use in [pagination](/docs/data/apis/horizon/api-reference/structure/pagination).

</ResponseField>

<ResponseField name="seller" type="string">

The account ID of the account making this offer.

</ResponseField>

<ResponseField name="selling" type="asset code">

The asset this offer wants to sell.

</ResponseField>

<ResponseField name="buying" type="asset code">

The asset this offer wants to buy.

</ResponseField>

<ResponseField name="amount" type="string">

The amount of `selling` that the account making this offer is willing to sell.

</ResponseField>

<ResponseField name="price_r" type="object">

A precise representation of the buy and sell price of the assets on offer.

  <Expandable title="price_r properties">
    <ResponseField name="n" type="number">

      The numerator.

    </ResponseField>

    <ResponseField name="d" type="number">

      The denominator.

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="price" type="string">

How many units of `buying` it takes to get 1 unit of `selling`. A number representing the decimal form of `price_r`.

</ResponseField>

<ResponseField name="last_modified_ledger" type="integer">

The sequence number of the last ledger in which this offer was modified.

</ResponseField>

<ResponseField name="last_modified_time" type="string">

An ISO 8601 formatted string of last modification time.

</ResponseField>

<ResponseField name="sponsor" type="string (optional)">

The account id of the sponsor who is paying the reserves for this offer.

</ResponseField>

The [latest ledger](../../structure/consistency) known to Horizon is included as an HTTP header in the response.
