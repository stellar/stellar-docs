When Horizon returns information about a ledger, it uses the following format:

<ResponseField name="id" type="string">
  A unique identifier for this ledger.
</ResponseField>

<ResponseField name="paging_token" type="number">
  A cursor value for use in [pagination](/docs/data/apis/horizon/api-reference/structure/pagination).
</ResponseField>

<ResponseField name="hash" type="string">
  A hex-encoded SHA-256 hash of this ledger’s [XDR](../../../../../../learn/fundamentals/data-format/xdr)-encoded form.
</ResponseField>

<ResponseField name="prev_hash" type="string">
  The hash of the ledger immediately preceding this ledger.
</ResponseField>

<ResponseField name="sequence" type="number">
  The sequence number of this ledger, and the parameter used in Horizon calls that require a ledger number.
</ResponseField>

<ResponseField name="successful_transaction_count" type="number">
  The number of successful transactions in this ledger.
</ResponseField>

<ResponseField name="failed_transaction_count" type="number">
  The number of failed transactions in this ledger.
</ResponseField>

<ResponseField name="operation_count" type="number">
  The number of operations applied in this ledger.
</ResponseField>

<ResponseField name="tx_set_operation_count" type="number">
  The number of total operations in the transaction set (including failed transactions).
</ResponseField>

<ResponseField name="closed_at" type="string">
  An [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) formatted string of when this ledger was closed.
</ResponseField>

<ResponseField name="total_coins" type="string">
  The total number of lumens in circulation.
</ResponseField>

<ResponseField name="fee_pool" type="string">
  The sum of all transaction fees.
</ResponseField>

<ResponseField name="base_fee_in_stroops" type="number">
  The fee the network charges per operation in a transaction.
</ResponseField>

<ResponseField name="base_reserve_in_stroops" type="number">
  The reserve the network uses when calculating an account’s minimum balance.
</ResponseField>

<ResponseField name="max_tx_set_size" type="number">
  The maximum number of operations validators have agreed to process in a given ledger. Since Protocol 11, ledger capacity has been measured in operations rather than transactions. For more info on that decision, see [CAP-5](https://github.com/stellar/stellar-protocol/blob/master/core/cap-0005.md#repurposing-ledgerheadermaxtxsetsize).
</ResponseField>

<ResponseField name="protocol_version" type="number">
  The protocol version that the Stellar network was running when this ledger was committed.
</ResponseField>

<ResponseField name="header_xdr" type="string">
  A base64 encoded string of the raw `LedgerHeader` xdr struct for this ledger.
</ResponseField>
