title: Trades
description: "When an offer is fully or partially fulfilled, a trade happens. Trades can also be caused by successful path payments, because path payments involve fulfilling offers."
order: 0
---

A trade occurs between two parties—`base` and `counter`. Which is which is either arbitrary or determined by the calling query.

Learn more about [trades](/docs/learn/glossary#decentralized-exchange).
