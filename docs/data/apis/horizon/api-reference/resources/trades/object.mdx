When Horizon returns information about a trade, it uses the following format:

<ResponseField name="id" type="string">

A unique identifier for this trade.

</ResponseField>

<ResponseField name="paging_token" type="number">

A cursor value for use in [pagination](/docs/data/apis/horizon/api-reference/structure/pagination).

</ResponseField>

<ResponseField name="ledger_close_time" type="string">

An ISO 8601 formatted string of when the ledger with this trade was closed.

</ResponseField>

<ResponseField name="base_account" type="string (optional)">

The account ID of the base party for this trade.

</ResponseField>

<ResponseField name="base_offer_id" type="string (optional)">

The base offer ID. If this offer was immediately and fully consumed, this will be a synethic ID.

</ResponseField>

<ResponseField name="base_liquidity_pool_id" type="string (optional)">

The base liquidity pool ID. If this trade was executed against a liquidity pool.

</ResponseField>

<ResponseField name="base_amount" type="string">

The amount of the base asset that was moved from `base_account` to `counter_account`.

</ResponseField>

<ResponseField name="base_asset_type" type="string">

The type for the base asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.

</ResponseField>

<ResponseField name="base_asset_code" type="string">

The code for the base asset.

</ResponseField>

<ResponseField name="base_asset_issuer" type="string">

The Stellar address of the base asset’s issuer.

</ResponseField>

<ResponseField name="counter_account" type="string (optional)">

The account ID of the base party for this trade.

</ResponseField>

<ResponseField name="counter_offer_id" type="string (optional)">

The counter offer ID. If this offer was immediately and fully consumed, this will be a synethic ID.

</ResponseField>

<ResponseField name="counter_liquidity_pool_id" type="string (optional)">

The counter liquidity pool ID. If this trade was executed against a liquidity pool.

</ResponseField>

<ResponseField name="counter_amount" type="string">

The amount of the counter asset that was moved from `counter_account` to `base_account`.

</ResponseField>

<ResponseField name="counter_asset_type" type="string">

The type for the counter asset. Either `native`, `credit_alphanum4`, or `credit_alphanum12`.

</ResponseField>

<ResponseField name="counter_asset_code" type="string">

The code for the counter asset.

</ResponseField>

<ResponseField name="counter_asset_issuer" type="string">

The Stellar address of the counter asset’s issuer.

</ResponseField>

<ResponseField name="price" type="object">

An object of a number numerator and number denominator that represents the original offer price. To derive the price, divide `n` by `d`. `n` and `d` are represented as strings because they might be 64-bit integers.

  <Expandable title="price properties">
    <ResponseField name="n" type="string">

      The numerator.

    </ResponseField>

    <ResponseField name="d" type="string">

      The denominator.

    </ResponseField>

  </Expandable>
</ResponseField>

<ResponseField name="base_is_seller" type="boolean">

Indicates with party is the seller.

</ResponseField>
