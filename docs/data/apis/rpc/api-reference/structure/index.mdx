How the RPC API is structured.

<CardGroup cols={2}>
  <Card title="JSON-RPC" icon="file-lines" href="/docs/data/apis/rpc/api-reference/structure/json-rpc">

    Stellar-RPC will accept HTTP POST requests using the JSON-RPC 2.0 specification.

  </Card>
  <Card title="Pagination" icon="file-lines" href="/docs/data/apis/rpc/api-reference/structure/pagination">

    For methods which support it, the pagination arguments are passed as a final object argument with two values.

  </Card>
  <Card title="Data Formats" icon="file-lines" href="/docs/data/apis/rpc/api-reference/structure/data-format">

    In the Stellar network, transactions are encoded using a standardized protocol called External Data Representation (XDR).

  </Card>
</CardGroup>
