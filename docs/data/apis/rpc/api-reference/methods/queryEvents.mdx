To use it, run RPC from the [`archive-node-beta`](https://github.com/stellar/stellar-rpc/releases/tag/archive-node-beta) tag or connect to a provider that offers one.

This method is in beta and may change before general availability.

### Errors

Invalid requests return JSON-RPC error code `-32602`. Because the human-readable error message may vary, use `error.data.reason` to identify the cause. Additional fields in `error.data` depend on the reason.

| `error.data.reason` | Other fields in `error.data` | Cause |
| --- | --- | --- |
| `invalid_params` | `termsUsed` and `termBudget` when the filter term budget is exceeded | An unknown field, invalid value, combination of initial-query and cursor parameters, or too many filter terms. |
| `ledger_out_of_range` | `missingLedger`, `oldestLedger`, `latestLedger` | A requested range boundary or cursor position is outside the ledgers available on this node. If below `oldestLedger`, restart from the oldest available ledger or use a node with deeper history. If above `latestLedger`, retry when that ledger becomes available. |
| `cursor_malformed` | `oldestLedger`, `latestLedger` | The cursor is invalid or cannot be parsed. Start a new query. |

Other failures return a JSON-RPC internal error without additional error data.
