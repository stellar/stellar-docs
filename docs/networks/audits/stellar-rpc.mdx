# Stellar RPC

Audits of [stellar-rpc](https://github.com/stellar/stellar-rpc), the RPC server for interacting with the Stellar network and Soroban contracts.

| Version | Auditor | Audit |
| --- | --- | --- |
| `commit a60044e` | OtterSec | [Soroban RPC Security Assessment](/assets/audits/2024-12-20%20-%20OtterSec%20-%20stellar-rpc%20commit%20a60044e.pdf) |

The assessment ran November 27 to December 11, 2024, against a snapshot from the v22.1 release series. Remediations for all findings were released in [v22.1.2](https://github.com/stellar/stellar-rpc/releases/tag/v22.1.2).
